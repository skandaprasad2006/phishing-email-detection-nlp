# AI-Based Phishing Email Detection Using NLP

Reproducible experiment suite for a TF-IDF + Random Forest / Logistic Regression
phishing-email classifier on the CEAS-08 corpus.

The implementation in `src/` replaces the original five Colab scripts, which fitted
TF-IDF on the whole dataset before splitting (data leakage) and reported accuracy
only. Every number this suite produces is measured from the dataset at run time;
nothing is hard-coded. See `HANDOVER.md` for the full audit.

## Quick start

```bash
pip install -r requirements.txt

# put CEAS_08.csv (or CEAS_08.csv.zip) in data/, then:
python -m src.run_experiments --data data --tag main
```

Outputs land in `results/` and `reports/`.

On Colab, open `notebooks/phishing_detection_colab.ipynb` and run the cells in
order.

### Verify the code without the dataset

```bash
python -m src.run_experiments --synthetic 900 --tag smoke --quick --cv-folds 3
```

Writes to `results/_smoke/` and `reports/_smoke/`, never to the real output
folders. **Synthetic numbers are never results.**

### Flags

| Flag | Effect |
|---|---|
| `--data PATH` | CSV or `.csv.zip`; defaults to the first file in `data/` |
| `--tag NAME` | `main` writes to `results/`/`reports/`; anything else writes to `_NAME` |
| `--quick` | 25 trees, for code testing only |
| `--cv-folds N` | cross-validation folds (default 5) |
| `--skip-cv`, `--skip-ablation`, `--skip-errors`, `--skip-legacy` | skip stages |
| `--max-single-latency-samples N` | how many emails to time individually |

## What the pipeline does

```
raw body text
   -> stateless per-document cleaning (HTML, URLs, case, punctuation)
   -> stratified 80/20 split of the *raw text*
   -> Pipeline: TfidfVectorizer (fit on train only) -> classifier
   -> metrics, ROC, confusion matrix, CV, ablation, error analysis, cost
```

Text cleaning is stateless, so it may run before the split without leaking. Every
transform that learns from data sits inside the `Pipeline` and is fitted on the
training partition only - including inside each cross-validation fold.

Verified at run time: the body and label column names, the label encoding, and the
positive-class index in `predict_proba`. If any of these differ, the run stops
instead of guessing.

## Outputs

| File | Contents |
|---|---|
| `results/model_metrics.csv` | accuracy, precision, recall, F1, ROC-AUC, TP/TN/FP/FN, FPR, FNR, specificity, NPV for both models + baseline |
| `results/roc_curve.png` | both ROCs, chance line, AUC in the legend |
| `results/confusion_matrix_{rf,lr}.png` | annotated counts and row-normalised rates |
| `results/feature_importance.{png,csv}` | top-20 Random Forest TF-IDF features |
| `results/threshold_analysis_{rf,lr}.csv` | FP/FN trade-off across thresholds |
| `results/cross_validation_{summary,results}.csv` | per-fold and mean±std |
| `results/ablation_results.csv` | one-factor-at-a-time study |
| `results/error_samples_{rf,lr}.csv` | masked misclassified rows |
| `results/deployment_metrics.csv` | artifact size, latency, throughput |
| `results/legacy_protocol_comparison.csv` | leaky protocol reproduced for comparison |
| `results/dataset_statistics.json`, `reports/dataset_statistics.md` | measured dataset facts |
| `reports/initial_research_audit.md` | code defects + draft self-consistency checks |
| `reports/experimental_results.md` | everything measured, in one place |
| `reports/cross_validation_report.md`, `reports/error_analysis.md` | as named |
| `reports/limitations_and_future_work.md` | defensible scope |
| `reports/final_ieee_paper_audit.md` | reviewer-style assessment, incl. bibliography audit |
| `reports/experiment_log.md` | run configuration and output list |

## Layout

```
src/            pipeline, metrics, experiments, reports, CLI
notebooks/      Colab notebook (generated by tools/build_notebook.py)
tools/          notebook builder
data/           dataset (git-ignored)
results/        generated artifacts
reports/        generated Markdown
```

## Rules

- Numbers quoted in the paper must come from `results/`, never from memory.
- Holdout and cross-validation results are separate experiments; do not merge them.
- No cross-dataset or significance claims: neither was tested.
